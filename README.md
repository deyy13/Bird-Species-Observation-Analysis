# Bird Species Observation Analysis

## Domain
Environmental Studies, Biodiversity Conservation & Ecology

## Overview
Analysis of bird species observations across Forest and Grassland ecosystems 
monitored by the NCRN Bird Monitoring Program across 11 administrative units in 2018.

## Project Structure
| File | Description |
|------|-------------|
| `app.py` | Streamlit interactive dashboard |
| `Bird_Analysis.ipynb` | Main notebook — EDA, SQL, Visualizations |
| `Bird_Cleaned_Dataset.csv` | Cleaned and preprocessed dataset |
| `bird_observations.db` | SQLite database |
| `Bird_Species_Report.docx` | Full project report |

## Key Findings
- Forest habitats support greater bird species diversity than grasslands
- Bird activity peaks in early morning (5–9 AM) and during spring/summer
- 15,368 observations across 127 unique species
- Several PIF Watchlist species identified across both habitats

## Tools Used
- Python, Pandas, NumPy
- Plotly, Streamlit
- SQLite
- Jupyter Notebook
